# Entregas de la web profesional

El 7 de noviembre de 2026 el titular autorizó completar las entregas hacia IA aplicada, publicar el Site existente y guardar las mismas fuentes en GitHub. Se mantienen ocho módulos y el diseño editorial carbón/coral.

## Contenido de esta edición

1. **Enfoque de IA aplicada.** Presentación ES/EN basada en .NET, Power Platform, React e integración de modelos. Capturas reales de los dos proyectos web y hechos profesionales confirmados.
2. **Asistente documental.** Biblioteca pública, consulta ligera con extractos y fuentes, modelo descargable optativo, cancelación y alternativa para móviles sin WebGPU. Sin API de pago ni envío de preguntas.
3. **Evaluación abierta.** Doce preguntas por idioma, ejecución real del modelo, evidencia y revisión por pregunta, resultados descargables y reproducción en navegador. La procedencia de la revisión está explícita y se conservan los fallos.
4. **Integración y automatización.** Demo de solicitudes, idempotencia y estados con versión. Dominio y API .NET 10 ejecutables, contrato HTTP, 18 pasos compartidos, concurrencia y pruebas HTTP. Guías Power Automate ES/EN, con una frontera explícita entre diseño e implantación real.
5. **Trayectoria y conocimiento.** Recorrido profesional ampliado sin inventar biografía, accesos para empleo/proyectos/comunidad dentro del módulo existente y dos notas nuevas completas. Cinco notas originales y 26 rutas ES/EN, con SEO y enlaces recíprocos.

## Criterio de cierre

Construcción y comprobaciones de web, API y contrato; revisión real de demos, escritorio y móvil en ambos idiomas; publicación pública y verificación con GitHub; GitHub Actions terminado correctamente y árbol local limpio. El registro local de ambos destinos se actualiza después de verificar la entrega.

## Material que solo puede aportar el titular

Historias personales, certificaciones, reconocimientos, testimonios, resultados empresariales y proyectos de clientes solo se incorporarán cuando existan y puedan publicarse. No son secciones vacías ni afirmaciones que haya que inventar para completar esta edición. Un despliegue real en Microsoft 365, datos privados o servicios de pago sería otro encargo con su entorno y permisos.

No hay trabajos recurrentes ni sincronización en segundo plano. Se conservan accesibilidad, consentimiento, contacto verificado, música optativa y fotografía normal; no se recupera el 3D retirado.
